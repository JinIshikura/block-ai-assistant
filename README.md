# ブロックAIアシスタント（サーバー版 v0.12）

Scratchのエディタに、子ども向けのAIアシスタントを追加するしくみです。

- **extension/**：Chromeの拡張機能（つなぎ役）。Scratchの上のバーにボタンを出し、サーバーの画面を重ねて、Scratchの中身の読み書きを取りつぐだけ。めったに更新しない。
- **public/**：Cloudflare Pagesで配る画面（`/app/`）と設定（`/config.json`）。ふだんの更新はここ。GitHubに置くと自動で反映される。
- **functions/api/**：AIの中継（`/api/claude`）。APIキーはCloudflareのシークレットにだけ保存する。

## 先生がはじめにすること（1回だけ）

1. Cloudflare Pages の設定 → 「変数とシークレット」に、次の2つを **シークレット（暗号化）** で登録し、再デプロイする
   - `ANTHROPIC_API_KEY`：AnthropicのAPIキー（Claude Consoleで作成。月の利用上限を低めに設定しておく）
   - `CLASS_CODE`：教室コード（好きな合言葉。各PCの設定画面に入れる）
2. `https://block-ai-assistant.pages.dev/api/health` を開き、`"ai":true` になっていることを確かめる

## 各PCですること（1回だけ）

1. このリポジトリの `extension` フォルダをPCに置く
2. Chromeで `chrome://extensions` を開き、「デベロッパーモード」をオン →「パッケージ化されていない拡張機能を読み込む」で `extension` フォルダを選ぶ（古い v0.10 は削除する）
3. Scratchの作品を開き、上のバーの「AIに聞く」→ ⚙ →「先生用の設定」で、教室コードなどを入れる

## 学習モード（v0.12〜）

- 普段のモードとは別の画面。先生の「土台作品」を別のタブで開いて使うので、子どもの作品には何も読みこまない
- 準備（1回だけ）：先生のScratchアカウントで空の作品を1つ作って「共有」し、作品の番号（URLの数字）を `public/config.json` の `learn.baseProject` に入れる。入れると、上のバーに「学習」ボタンが出る
- いまの課題（全42問、`tools/course.py` で作り直せる）：ステップ1「読む」（第1回 1つのブロックは1行／第2回 上から順番に／第3回 くり返しと字下げ／第4回 もし〜なら／第5回 変数／まとめ）、ステップ2「直す」（第6回 記号／第7回 字下げ／第8回 エラー／まとめ）、ステップ3「書く」（第9回 input()／第10回 条件つきのくり返しと乱数／第11回 まとまりとメッセージ／第12回 リスト／第13回 Scratchの外のPython／まとめ）。スライドはブロックとコードを行ごとに並べた対応表で表示し、演習では「ブロックと見比べる」で切りかえられる。説明していないコードを演習で使っていないかは `tests/learn-taught-test.js` で確かめる
- ブロックとコードの対応表：学習モードの上の「対応表」、または `/table/`（印刷できる）
- 生徒ごとのログイン：先生は `/teacher/` の管理画面で生徒のIDと初期パスワードを作る。先生のID・パスワードは Cloudflare の TEACHER_ID・TEACHER_PASSWORD、生徒は KV（バインド名 USERS）に保存（パスワードはハッシュ）。シミュレーション用の生徒 sim01 は、先生が一覧を開くと自動で作られる。ログインのしくみが設定されていると、アプリを開いたときにログイン画面が出る
- コード欄の入力サポート（`public/app/editorassist.js`）：入力候補（Ctrl+Space）、かっこ・引用符の自動入力、自動の字下げ、全角→半角の自動修正、対応かっこと今の行の強調、案内バー（命令の使い方・書きまちがい）、Ctrl+/ でコメント。学習モードと普段のコード欄の両方で使う
- 課題：`public/learn/course.json`（スライド・演習・ヒント・判定の条件）と `public/learn/*.sb3`（最初の状態）。`tools/build_sb3.py` で作る
- 判定：コードの形（ブロックにしてからコードに戻した形で、行と字下げを確かめる）＋実際に動かした結果（位置・変数・言ったこと）
- AIは、判定で2回うまくいかなかったときだけ、ヒントを聞ける（答えのコードは出さない）。答えの表示はない。記録は残さない

## 更新のしかた

- 画面・コード変換・AIへの指示・学習課題：`public/` を更新してGitHubに置くだけ（各PCは次に開いたときに新しくなる）
- 上のバーのボタンの名前や場所：`public/config.json` を更新するだけ
- Scratchの中身の読み書きに新しい操作を足すとき：`extension/` を更新し、各PCで入れ替える（まれ）

## 安全のために

- 拡張機能は `https://block-ai-assistant.pages.dev` からの頼みしか取りつがない
- サーバーの画面は `https://scratch.mit.edu` の中でしか表示できない（`frame-ancestors`）
- `/api/claude` は、このサーバーのページから、正しい教室コードのときだけ使える。モデルと出力の長さはサーバー側で制限する
- 子どもの名前や住所は会話に書かせない。会話の記録（Googleスプレッドシート）は設定でオンにしたときだけ送る

## 開発メモ

- `docs/apps-script.gs`：会話の記録を受けとる Google Apps Script
- 設定・会話は各PCのブラウザ（サーバーの画面の保存領域）に保存される
